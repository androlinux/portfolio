# Деплой на Vercel — полная инструкция

Сайт уже готов к продакшену. Ниже два способа залить его на Vercel.
Способ A (через сайт Vercel + GitHub) — самый простой и рекомендуемый.
Способ B (через терминал) — быстрее, если не хочешь возиться с GitHub.

Обновления потом: при способе A достаточно запушить изменения в GitHub —
Vercel пересоберёт сайт сам. При способе B — повторить `vercel --prod`.

---

## Что важно знать

- Это статический сайт на Vite. Vercel сам выполнит `npm run build`
  и опубликует папку `dist/`. Ничего вручную собирать не нужно.
- Настройки сборки уже лежат в `vercel.json` (build command, output dir, кэш).
- Бесплатного тарифа Vercel (Hobby) более чем достаточно.

## Способ A — через GitHub (рекомендуется)

### Шаг 1. Установи Git (если ещё нет)
Скачай: https://git-scm.com/download/win — установи с настройками по умолчанию.

### Шаг 2. Создай аккаунт GitHub
https://github.com → Sign up (можно войти тем же email, что и в Vercel).

### Шаг 3. Создай новый репозиторий
1. На GitHub нажми `+` справа вверху → **New repository**
2. Имя: например `myrat-portfolio`
3. Оставь **Public** (или Private — без разницы)
4. НЕ ставь галочки «Add README» и т.п. — оставь пустым
5. **Create repository**

### Шаг 4. Залей проект в репозиторий
Открой папку `portfolio-app` в терминале (в проводнике: правый клик в папке →
«Открыть в терминале», или в cmd: `cd путь\к\portfolio-app`). Выполни по очереди:

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/myrat-portfolio.git
git push -u origin main
```

(Замени `ТВОЙ_ЛОГИН` на свой ник GitHub. URL можно скопировать со страницы репозитория.)

### Шаг 5. Подключи Vercel
1. Зайди на https://vercel.com → **Sign up** → войди через **Continue with GitHub**
2. Нажми **Add New… → Project**
3. Найди свой репозиторий `myrat-portfolio` → **Import**
4. Vercel сам определит, что это Vite. Настройки уже правильные:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Нажми **Deploy**

Через ~1 минуту сайт будет онлайн по адресу вида
`myrat-portfolio.vercel.app`.

### Обновление сайта потом
Поменял что-то в коде → в терминале:
```bash
git add .
git commit -m "update"
git push
```
Vercel пересоберёт и обновит сайт автоматически.

## Способ B — через терминал (без GitHub)

### Шаг 1. Установи Vercel CLI
```bash
npm install -g vercel
```

### Шаг 2. Войди
```bash
vercel login
```
(введёт email, придёт письмо для подтверждения)

### Шаг 3. Задеплой
Находясь в папке `portfolio-app`:
```bash
vercel
```
Ответь на вопросы (можно жать Enter — значения по умолчанию подойдут):
- Set up and deploy? → **Y**
- Which scope? → твой аккаунт
- Link to existing project? → **N**
- Project name? → Enter (или своё имя)
- In which directory is your code? → **.** (точка, Enter)
- Хочет переопределить настройки? → **N** (всё уже в vercel.json)

Получишь временную ссылку (preview). Чтобы опубликовать в продакшен:
```bash
vercel --prod
```

### Обновление потом
Просто снова запусти в папке:
```bash
vercel --prod
```

## Подключение своего домена (когда купишь)

1. В Vercel открой свой проект → вкладка **Settings → Domains**
2. Введи купленный домен (например `myrat.com`) → **Add**
3. Vercel покажет, какие DNS-записи прописать у регистратора домена:
   - Обычно запись **A** на `76.76.21.21`
   - и/или **CNAME** для `www` на `cname.vercel-dns.com`
4. Зайди в панель, где купил домен → раздел DNS → добавь эти записи
5. Подожди (от пары минут до пары часов) — Vercel сам выдаст бесплатный
   SSL-сертификат (https заработает автоматически)

## Проверка перед деплоем (необязательно)

Локально можно проверить именно продакшен-версию:
```bash
npm run build      # собрать
npm run preview    # открыть собранную версию
```

## Частые вопросы

**Нужно ли заливать папку `dist` или `node_modules`?**
Нет. Они в `.gitignore`. Vercel сам всё установит и соберёт.

**Админ-панель работает на продакшене?**
Да — открывается через **Ctrl + Shift + A**, логин `admin123`,
пароль `Muratadmin123`. Изменения сохраняются в localStorage браузера
(они локальны для каждого посетителя; чтобы менять контент «для всех» —
правь файлы в `src/data/` и передеплой).

**Сайт бесплатный навсегда?**
Тариф Hobby бесплатный для личных проектов. Домен — отдельная платная покупка
у регистратора, но подключение к Vercel и SSL бесплатны.
